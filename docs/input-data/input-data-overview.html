The input datasets: what they hold

A run starts from one input set: five Parquet tables and two YAML files, written once by the one-off steps O2–O4 and never edited afterwards. Together they describe a synthetic €11bn book of EUR loans at amortised cost on 31 December 2026, the rating matrices and parameters that move it, and the baseline and adverse economies of 2027–2029.

ttc_pd_matrix

Parquet847 rows × 7 columnskey segment, from_grade, to_grade

One through-the-cycle, one-year rating migration matrix per reference segment, stored long: one row per cell. Each matrix runs over ten performing grades G1–G10 and the absorbing default grade D, so 7 segments × 11 × 11 = 847 rows.
