This slide reports an independent check made for this review, outside the repository. One specification combined a seventh portfolio packaged with the new command, its own polynomial model with a one-year GDP lag and a squared term on a new inflation variable, a crisis inherited from adverse with one Italian override, a three-year terminal reversion, and dynamic volumes. The six original portfolios matched a control run to the nearest EUR 0.01m in baseline and adverse. The stock bridge closed to within EUR 0.00001 each year. Rerunning the example run made on main also reproduced all 51 outputs. One limit showed up: the workbook has no view by country. A country crisis can be read from the Z scores and from country stocks and provisions in a CSV, but no report gives charges by country.
