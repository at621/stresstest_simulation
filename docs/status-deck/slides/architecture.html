Architecture · One-off steps and engine share no code; import rules enforce it

4

Two parts that share no code. The one-off steps build the transcribed requirements and the hashed synthetic input set, and their only products are files. The run pipeline reads one input set and goes from R1 to R11. R7 to R9 repeat for each projected year. Only cli.py wires the steps together, and the steps share only contracts. Three import rules enforce that separation. The run ends in a sealed, read-only folder with a manifest of hashes, so a run can be replayed and compared. A blocking error also seals the run, as BLOCKED.
