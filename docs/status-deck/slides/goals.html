Before today’s merge, none of the six goals was fully met: dynamic assumptions and one specification were not done, and the other four were partial. Each limit on this slide was checked in code or by a test run. The specification rejects a horizon setting, rejects any status other than SYNTHETIC, and a run without baseline blocks at R4. Goal 5 is the closest call: there is one reference document and one run file, but at run time the base input set, the run file and an optional analysis file are three separate things, and the horizon, tolerances, master scale and variants stay in the base parameter set.
