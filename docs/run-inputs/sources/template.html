Every input a run reads

A run needs seven datasets and a manifest. A run specification, an analysis file and an approval record are optional. This page defines all of them: every column, setting and option, with what the engine does with each one.

The column lists, types and current values are generated from the engine's input contract and input set %%HASH%%. The build stops if a column, parameter or option has no definition. All current values are synthetic.

Rules for every table

  • Units. Amounts are EUR. Rates and probabilities are decimal fractions, so 3% is 0.03. Dates are text in YYYY-MM-DD.
  • Exact columns. A missing column blocks the run (MISSING_COLUMN), and so does an extra one (UNKNOWN_COLUMN). Column names are case-sensitive.
  • Booleans. Accepted as true or false, 1 or 0, or the text true, false, 1, 0. Anything else blocks: BAD_VALUE_TYPE.
  • Immutable sets. R2 hashes all seven files. To change a value, build a new input set. Changing a file blocks the run: INPUT_HASH_MISMATCH.
  • Blank column. "Blank: no" means a blank value in that column cannot pass. "Blank: yes" means the file may hold a blank, but a calculation that needs the value can still reject the record.

Value status: why a blank is never zero

Any column can have a companion named <column>__status. Without one, R2 infers the status: blank is missing, a numeric 0 is zero, and anything else is supplied. A stated status wins, but a blank stays missing unless it says not_applicable.

StatusMeaningA calculation may use it
suppliedA real value from the source.Yes
zeroA true zero.Yes
estimatedAn estimate.Yes
not_applicableThe field does not apply to this record.No
missingThe value should exist and does not.No

Rejected or blocked

  • Rejected: R3 drops the record, logs its reason code in rejections.parquet and carries on. A rejected commitment or provision also rejects its facility: LINKED_RECORD_REJECTED. Accepted plus rejected must still equal what was loaded.
  • Blocked: the whole run stops, exit code 2. Five rejection reasons always block: MISSING_CCF, CCF_OUT_OF_RANGE, NEGATIVE_AMOUNT, DUPLICATE_COMMITMENT and LIMIT_BREACH. So do hash, column, type and matrix errors.
